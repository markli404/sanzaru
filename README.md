# SANZARU website

Research website for [SANZARU](https://github.com/markli404/sanzaru-benchmark).

Live site: https://yipingli.dev/sanzaru/

Paper: https://arxiv.org/abs/2610.15163

This repository contains the standalone static website, figures, and selected released episode traces. It requires no build step. GitHub Pages publishes the root of the `main` branch.

To preview locally, run `python3 -m http.server 8000` from this directory and open http://localhost:8000.

The original hosted preview remains available at https://sanzaru-benchmark.nutty-snow-3860.chatgpt.site/.
